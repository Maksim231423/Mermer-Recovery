====================================================================
           ИНСТРУКЦИЯ ПО РАЗВЕРТЫВАНИЮ И ЗАПУСКУ MERMER ERP
====================================================================

Данный комплекс состоит из трех компонентов:
  1. Серверная часть (Docker: PostgreSQL + Backend API).
  2. Десктоп-клиент (Mermer ERP для Windows).
  3. Утилита переноса данных из Couchbase (Mermer Patcher).

--------------------------------------------------------------------
ШАГ 1. РАЗВЕРТЫВАНИЕ СЕРВЕРНОЙ ЧАСТИ (DOCKER)
--------------------------------------------------------------------
Серверную часть достаточно запустить один раз на главном компьютере 
или выделенном сервере компании.

1. Убедитесь, что на компьютере установлен и запущен Docker Desktop:
   - Значок кита в трее Windows должен быть зеленым / стабильным.
2. Распакуйте архив Mermer_Server.zip в нужную директорию на сервере 
   (например, D:\Mermer_Server).
3. Откройте командную строку (cmd или PowerShell) в этой папке.
4. Выполните команду запуска:
        docker compose up -d
5. Проверьте запуск контейнеров командой:
        docker ps
   В списке должны быть два активных контейнера:
   - mermer_postgres (порт 5433 -> 5432)
   - mermer_api (порт 5050 -> 5050)

--------------------------------------------------------------------
ШАГ 2. ПЕРЕНОС ДАННЫХ ИЗ СТАРОЙ СИСТЕМЫ (ПАТЧЕР)
--------------------------------------------------------------------
Утилиту миграции (Patcher) можно запустить двумя способами:

Способ А (Через установщик):
1. Откройте меню «Пуск» -> папка «Mermer ERP» -> выберите ярлык патчера.
   (Либо перейдите в папку установки: C:\Program Files\Mermer ERP\Tools\Patcher 
   и запустите Mermer.Data.Patcher.exe).

Способ Б (Напрямую через консоль / терминал):
1. Откройте PowerShell в папке с распакованным или собранным патчером.
2. Запустите утилиту командой:
        dotnet run --project "Путь_к_папке\Mermer.Data.Patcher.csproj"
   (или запустите скомпилированный бинарный файл Mermer.Data.Patcher.exe).

Порядок работы утилиты:
1. Консоль последовательно запросит параметры (если они верны, 
   просто нажимайте клавишу ENTER):
   - Хост [localhost]: (нажмите Enter)
   - Порт [5433]: (нажмите Enter)
   - База данных [mermer_creation]: (нажмите Enter)
   - Пользователь [mermer_creation]: (нажите Enter)
   - Пароль [******]: (нажмите Enter)
   - Путь к файлу экспорта: укажите полный путь к файлу binyat_export.json
     (например: D:\Программирование\binyat_export.json)
   - Очистить целевые таблицы перед импортом (TRUNCATE CASCADE)? [y/N]:
     * Введите y — если загружаете базу с нуля и хотите стереть старые тесты.
     * Введите n (или нажмите Enter) — если нужно дополнить данные.

2. Дождитесь появления зеленой надписи:
   «[УСПЕХ] Миграция данных полностью завершена!».
3. Нажмите любую клавишу для закрытия консоли.

--------------------------------------------------------------------
ШАГ 3. НАСТРОЙКА ПОДКЛЮЧЕНИЯ КЛИЕНТА (APPSETTINGS.JSON)
--------------------------------------------------------------------
Если клиентская программа установлена на том же компьютере, где 
запущен Docker, менять ничего не нужно.

Если клиент установлен на другом рабочем месте в сети:
1. Перейдите в папку с установленной программой:
   C:\Program Files\Mermer ERP (или путь, выбранный при установке).
2. Найдите файл appsettings.json, нажмите по нему правой кнопкой мыши -> 
   «Открыть с помощью» -> «Блокнот».
3. В строках "ApiUrl" и "ActivationUrl" замените localhost на сетевой 
   IP-адрес сервера с Docker:
   Было:
        "ApiUrl": "http://localhost:5050",
   Стало:
        "ApiUrl": "http://192.168.1.100:5050",
4. Нажмите Ctrl + S для сохранения файла.

--------------------------------------------------------------------
ШАГ 4. ЗАПУСК И РАБОТА С ПРОГРАММОЙ
--------------------------------------------------------------------
1. Запустите ярлык «Mermer ERP» с рабочего стола.
2. Авторизуйтесь под учетной записью администратора.
3. Проверьте основные разделы:
   - «Счета / Bills»: финансовые приходные и расходные документы.
   - «Накладные / Invoices»: продажи и закупки.
   - «Номенклатура и Склады»: остатки товаров и актуальные цены.
   - «Контрагенты»: база клиентов и поставщиков.

--------------------------------------------------------------------
ТЕХНИЧЕСКАЯ ПОДДЕРЖКА
--------------------------------------------------------------------
При возникновении сетевых ошибок (код 500 / Connection Refused):
- Убедитесь, что Docker запущен на сервере.
- Проверьте доступность порта 5050 через Брандмауэр Windows.
